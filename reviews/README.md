# reviews/

Dated review notes for this repo. One file per review pass.

Naming: `YYYY-MM-DD-<slug>.md`

Each file records what was reviewed, the findings ranked by severity, and — as
fixes land — which commit closed each finding. A finding is only struck off here
once the fix is committed, so this folder doubles as the project's punch list.

| File | Date | Scope |
|------|------|-------|
| `2026-09-13-initial-review.md` | 2026-09-13 | First full read of the generated codebase |
